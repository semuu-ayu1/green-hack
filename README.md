# Green Hack

A TypeScript-based alumni portal project designed to manage and connect alumni networks.

## Overview

Green Hack is a web application built to facilitate alumni engagement and community building. It provides tools for alumni to stay connected, share experiences, and maintain relationships with their educational institution.

## Features

- **Alumni Management**: Organize and manage alumni information
- **Networking**: Connect alumni members and facilitate community building
- **Profile Management**: Create and maintain alumni profiles
- **TypeScript Support**: Built with TypeScript for type-safe development

## Tech Stack

- **Language**: TypeScript
- **Type**: Web Application

## Getting Started

### Prerequisites

- Node.js (recommended version 14+)
- npm or yarn package manager

### Installation

1. Clone the repository:
```bash
git clone https://github.com/semuu-ayu1/green-hack.git
cd green-hack
```

2. Install dependencies:
```bash
npm install
# or
yarn install
```

### Usage

```bash
npm start
# or
yarn start
```
